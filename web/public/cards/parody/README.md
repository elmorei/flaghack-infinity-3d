# Original Frick-frack parody cards

The atlas is the original generated concept sheet requested for Frick-frack, reused without modifying its art. It is not an imported commercial trading-card deck.

Source: the game's generated `frick-frack-cheat-card-concept-sheet.png`, 1536 × 1024 pixels. The runtime file is mechanically encoded as `frick-frack-cheat-card-atlas.webp` at WebP quality 85, with original dimensions and artwork preserved. Original PNG sources are retained outside the repository and in the source Library artifact.

Three original families contain seven cards each: Mana Misfits, Pocket Problems, and Duel Nonsense. Each card's game value is the explicitly printed VALUE 1–7. Decorative HP, attack/defense, abilities, and resource symbols do not affect blackjack. The value 1 is literally one, not an ace worth eleven.

These 21 cards are added to the 52 ordinary and 56 minor-arcana cards, and can also appear in the one-use cheat sideboard. CSS sprite windows isolate each original rectangle; numeric badges and accessible labels make the actual gameplay value explicit.

## Bench Legends — original sports CCG family

`bench-legends-atlas.webp` is original AI-generated pixel-art artwork, generated with the built-in image tool on 2026-10-29. No real athlete portraits or team logos were requested. This separate 1536×1024 atlas has four columns and two rows; the last cell is intentionally unused. It is mechanically encoded at WebP quality 85 without changing dimensions or artwork, and framed using CSS background rectangles. The original generated PNG remains outside the repository.

The seven fictional athletes' visible jersey numbers are their literal blackjack values (1 is not an ace): Bunt Bixby 1, Airball Ada 2, Fumble Finn 3, Offside Olive 4, Brick Baxter 5, Turf Tessa 6, Whiff Wally 7. They belong to CCG family 3 and follow the same collectible/battle rules as the other parody families.

Generation prompt: one seven-card retro 16-bit pixel sports trading-card atlas in a four-by-two grid, gold/cream frames and navy stadium backgrounds; fictional baseball, basketball, American football and soccer athletes; each athlete displays its jersey number 1–7, matching VALUE badge and exact name header; BENCH LEGENDS footer; no real athletes, commercial logos, extra stats or overlapping cells.

Runtime atlas sizes: original three-family atlas 466,878 bytes; Bench Legends 355,566 bytes. Both remain 1536×1024.
